# 데이터와 모델 저장

GitHub에는 코드, 설정, 문서, 실험 기록을 올립니다.
GitHub 저장소 복제는 코드 공유이며 자동 파일 동기화나 GPU 학습 서비스가 아닙니다.

| 로컬 위치 | 내용 |
| --- | --- |
| data/ | 입력 영상과 주석 |
| models/ | 모델 가중치 |
| outputs/ | 생성 영상과 마스크 |

각 폴더는 README.md를 제외한 실제 파일을 Git에서 제외합니다.
대표 영상·가중치 확장자도 폴더 위치와 관계없이 제외합니다.
Git 제외 규칙은 이미 추적된 파일에는 소급 적용되지 않으므로 커밋 전에 git diff --cached를 확인합니다.

공용 대용량 저장 서비스는 미정입니다. 이 폴더들은 클라우드 공간이 아닙니다.
용량과 공개 가능 범위를 확인한 뒤 서비스를 선정하고 실제 링크를 여기에 기록합니다.

공유 파일은 파일명, 출처, 사용 가능 범위, 용량, 버전, SHA-256, 접근 링크를 실험 기록에 남깁니다.
아직 없는 업로드 주소나 모델 파일을 문서에 존재하는 것처럼 기록하지 않습니다.
